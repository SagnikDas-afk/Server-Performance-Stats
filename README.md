# Server-Performance-Stats
Goal of this project is to write a script to analyse server performance stats.

https://roadmap.sh/projects/server-stats

A lightweight Bash script designed to provide a quick snapshot of a Linux server's health.
This project is part of the roadmap.sh backend challenges.

🚀 FeaturesThe script provides the following real-time statistics:

- CPU Usage: Total percentage of CPU currently in use.

- Memory Usage: Breakdown of used vs. free memory, including percentage.

- Disk Usage: Breakdown of used vs. free disk space, including percentage.

- Process Analysis:
  
  - Top 5 processes by CPU consumption.

  - Top 5 processes by Memory consumption.

🛠️ Installation & Usage

1. Clone the repository:
   
     `git clone https://github.com/SagnikDas-afk/Server-Performance-Stats.git`
   
     `cd server-performance-stats`
2. Make the script executable:

   `chmod +x server-stats.sh`

3. Run the script:
   
   `./server-stats.sh`
